# DATA CONTOH YANG HARUS DIGANTI

Tabel berikut mencantumkan data contoh yang masih dipakai untuk keperluan prototipe. Setelah data resmi masuk, pengurus wajib mengganti data di file-file berikut agar situs siap publikasi.

| Jenis data | Lokasi | Catatan pengganti |
|---|---|---|
| Nama masjid | `data/config.json` | Ganti dengan nama resmi masjid dan data asli |
| Tahun berdiri | `data/config.json` | Sesuaikan dengan tahun pendirian resmi |
| Daya tampung | `data/config.json` | Ubah jika kapasitas benar-benar berbeda |
| Alamat lengkap | `data/config.json` | Gunakan alamat resmi dan konsisten di seluruh halaman |
| Plus Code / koordinat | `data/config.json` | Update agar peta dan arah sesuai lokasi asli |
| Telepon/WhatsApp | `data/config.json`, semua halaman HTML | Ganti nomor resmi pengurus |
| Email | `data/config.json`, halaman kontak | Gunakan email resmi masjid |
| Sosial media | `data/config.json` | Ganti ke akun resmi yang aktif |
| Pengurus dan jabatan | `data/pengurus.json` | Isi nama, jabatan, serta kontak nyata |
| Fasilitas | `data/fasilitas.json` | Sesuaikan dengan kondisi aktual |
| Kegiatan rutin | `data/kegiatan.json` | Update jadwal dan pemateri yang benar |
| Pengumuman | `data/pengumuman.json` | Hapus/ubah dengan pengumuman resmi |
| Donasi dana | `data/donasi.json` | Jaga target, saldo, rekening, dan periode sesuai data asli |
| Kebutuhan barang | `data/kebutuhan-barang.json` | Update jumlah, prioritas, dan status |
| Rekening bank | `data/donasi.json` | Wajib sesuai rekening resmi dan diaudit pengurus |
| QRIS | `data/donasi.json`, `assets/images/qris-placeholder.svg` | Ganti dengan QRIS resmi yang valid |
| Keuangan | `data/keuangan/index.json`, `data/keuangan/*.json` | Hanya tampilkan laporan yang sudah diverifikasi |
| Artikel berita | `berita/*.html` | Ganti dengan artikel real dan sumber yang valid |
| Galeri | `data/galeri.json` | Gunakan foto resmi dan sesuai lisensi |
| Label data contoh | semua HTML | Hapus lencana dan banner setelah data resmi dimasukkan |
| noindex | semua halaman HTML | Hapus tag noindex saat situs siap publikasi |

Catatan: data contoh bersifat fiktif dan tidak boleh dipakai sebagai referensi konten atau rekening resmi.
